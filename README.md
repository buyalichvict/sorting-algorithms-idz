# Эмпирический и теоретический анализ алгоритмов сортировки

**ФИО:** Буялич Виктория Константиновна

**Группа:** Б06-505

**Вариант:** Bubble Sort (с флагом), Selection Sort, Merge Sort, Timsort (упрощённый)

## О проекте
Индивидуальное домашнее задание по дисциплине «Информатика и алгоритмизация».
Цель — сравнить эмпирическое время работы и теоретическую сложность различных алгоритмов сортировки на разных типах входных данных.

## Технологии
- Python 3.13
- Jupyter Notebook
- Библиотеки: numpy, pandas, matplotlib, scipy

## Как запустить
1. Клонируйте репозиторий:
   git clone https://github.com/buyalichvict/sorting-algorithms-idz.git
2. Установите зависимости:
   pip install -r requirements.txt
3. Запустите Jupyter Notebook:
   jupyter notebook
4. Откройте файл sorting_project.ipynb и выполните все ячейки сверху вниз.
